# Landing Page Website Specification

## Purpose

Simple marketing website to drive app downloads. Similar to Instagram, TikTok, Venmo - no web app features, just promotion.

---

## Pages

### 1. Home/Landing Page

**Sections (Top to Bottom):**

1. **Hero Section**
   - Large headline: "All-in-One Social Finance & Living App"
   - Subheadline: "Split expenses, manage finances, coordinate chores, find roommates - all in one place"
   - Download buttons: App Store + Play Store (prominent, above fold)
   - Hero image: Phone mockup with app screenshot

2. **Value Proposition**
   - "Why Dream Finora?" section
   - Key benefits in cards:
     - ✅ All features in one app
     - ✅ Trust scores for reliability
     - ✅ No transaction limits
     - ✅ Free to use

3. **Features Section**
   - Grid of feature cards with icons:
     - Expense Splitting
     - Personal Finance
     - Chore Management
     - Rideshare Tracking
     - Community Listings
     - Trust Scores
   - Brief description for each

4. **Screenshots Gallery**
   - 4-6 app screenshots in carousel
   - Shows key screens:
     - Home dashboard
     - Expense creation
     - Profile with trust score
     - Chore management
     - Personal finance

5. **How It Works**
   - Simple 3-step process:
     1. Download app
     2. Create account
     3. Start managing shared life

6. **Testimonials** (Future)
   - User testimonials
   - Trust indicators

7. **Download CTA**
   - Large download buttons again
   - "Available on iOS and Android"

8. **Footer**
   - Links:
     - About
     - Privacy Policy
     - Terms of Service
     - Contact
     - Support
   - Social media links (if applicable)
   - Copyright

### 2. About Page
- Company mission
- Story/vision
- Team (if applicable)
- Contact information

### 3. Privacy Policy Page
- Standard privacy policy
- Data collection practices
- User rights

### 4. Terms of Service Page
- Standard terms
- Usage guidelines
- Liability

---

## Design

### Style
- Modern, clean, conversion-focused
- Match mobile app design language (Primary Blue #2563EB)
- Mobile-responsive
- Fast loading (< 2 seconds)

### Components Needed
- Hero section
- Feature cards
- Screenshot gallery/carousel
- Download buttons (App Store + Play Store badges)
- Footer
- Navigation header

### Assets Needed
- App screenshots (4-6 high-quality)
- Phone mockup images
- Logo
- App Store badges (official Apple/Google assets)
- Icons for features

---

## Technical Requirements

### Framework
- Next.js 14+ (static site generation)
- TypeScript
- Tailwind CSS

### Features
- ✅ Static pages (no server-side logic)
- ✅ SEO optimized
- ✅ Fast loading
- ✅ Mobile-responsive
- ✅ Analytics ready (Google Analytics)
- ❌ NO authentication
- ❌ NO API calls to backend
- ❌ NO user accounts
- ❌ NO app features

### Deployment
- Vercel (free tier)
- Custom domain (optional)

---

## Content Strategy

### Messaging
- Focus on benefits, not features
- Emphasize "all-in-one" convenience
- Highlight trust scores
- Mention free tier (no limits)

### Call-to-Actions
- Primary: Download buttons (above fold, multiple placements)
- Secondary: Learn more, View features

---

## Success Metrics

### Goals
- Drive app downloads
- Showcase app features
- Build trust
- Provide support information

### Analytics to Track
- Page views
- Download button clicks
- Time on page
- Bounce rate
- Conversion to app download
