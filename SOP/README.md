# Standard Operating Procedures (SOP)

## Purpose

This directory contains all **locked and final** project documentation. These documents define the project vision, architecture, features, and specifications. **DO NOT MODIFY** these files during development - they are the source of truth.

## Important Rules

### ❌ DO NOT MODIFY
- These files are **LOCKED**
- They represent the final, approved plan
- Changes would cause misalignment

### ✅ DO MODIFY
- `docs/DAILY_LOGS/` - Your daily progress
- `docs/DECISIONS/` - New decisions (add new ADRs)
- `docs/ISSUES/` - Track bugs and solutions
- `docs/PROGRESS.md` - Update progress
- `docs/CHANGELOG.md` - Version history

### 📝 If Changes Needed
If you discover something that requires changing these docs:
1. Document it in `docs/DECISIONS/` as an ADR
2. Discuss with me first
3. We'll update SOP files together if approved
