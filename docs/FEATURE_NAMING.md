# Feature Naming Convention

This document defines the catchy, user-friendly names for all features in Dream Finora.

## Core Features

### ✅ Split Expenses
- **Feature Name:** `Billchop`
- **Description:** Split bills and expenses with friends, roommates, or groups
- **Icon/Symbol:** ✂️ (scissors/chop)
- **Why:** Short, catchy, clearly indicates splitting bills

### ✅ Profile
- **Feature Name:** `My Space`
- **Description:** View and edit your profile, trust score, and personal information
- **Icon/Symbol:** 👤 or 🏠
- **Why:** Personal, friendly, indicates ownership

### ✅ Groups
- **Feature Name:** `Circles`
- **Description:** Create and manage groups (roommates, friends, etc.)
- **Icon/Symbol:** ⭕ or 👥
- **Why:** Social, indicates groups of people, easy to understand

### ✅ Personal Finance
- **Feature Name:** `My Wallet`
- **Description:** Track personal income, expenses, and account balances
- **Icon/Symbol:** 💰 or 👛
- **Why:** Universal, clear, indicates personal money management

### ✅ Chores
- **Feature Name:** `Chore Board`
- **Description:** Manage household tasks and chores with points system
- **Icon/Symbol:** ✅ or 📋
- **Why:** Clear, indicates task management, familiar concept

### ✅ Rideshare
- **Feature Name:** `Ride Pool`
- **Description:** Share rides and track ride expenses
- **Icon/Symbol:** 🚗 or 🚕
- **Why:** Clear, indicates sharing/carpooling

### ✅ Listings
- **Feature Name:** `Market`
- **Description:** Browse and create listings (roommates, items, events, etc.)
- **Icon/Symbol:** 🛒 or 🏪
- **Why:** Universal, indicates buying/selling/listing

### ✅ Messaging
- **Feature Name:** `Messages`
- **Description:** Direct messaging and conversations
- **Icon/Symbol:** 💬
- **Why:** Simple, familiar, no confusion

### ✅ Analytics - Personal Finance
- **Feature Name:** `Insights`
- **Description:** Financial insights and analytics for personal finance
- **Icon/Symbol:** 📊 or 💡
- **Why:** Modern, indicates deeper understanding, analytics

### ✅ Analytics - Split Expenses
- **Feature Name:** `Billchop Analytics` or `Spending`
- **Description:** Analytics for split expenses (Billchop)
- **Icon/Symbol:** 📈
- **Why:** Clear distinction, indicates expense tracking

## Navigation Labels

All navigation buttons and tabs should use the feature names above:
- `Billchop` instead of "Expenses"
- `My Space` instead of "Profile"
- `Circles` instead of "Groups"
- `My Wallet` instead of "Finance"
- `Chore Board` instead of "Chores"
- `Ride Pool` instead of "Rides"
- `Market` instead of "Listings"
- `Insights` instead of "Analytics" (for personal finance)
- `Billchop Analytics` for split expense analytics

## Implementation Notes

1. All user-facing text should use these names
2. Internal code can still use technical names (expense, profile, etc.)
3. Keep consistency across all screens
4. Use the feature names in:
   - Home screen buttons
   - Screen titles
   - Navigation labels
   - Empty states
   - Error messages
   - Help text
