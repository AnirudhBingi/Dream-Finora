### Backend Pagination Implementation:

All list endpoints now support pagination with `limit` and `offset` parameters:
- `GET /expenses` - Returns `{ expenses, total, limit, offset, hasMore }`
- `GET /chores` - Returns `{ chores, total, limit, offset, hasMore }`
- `GET /groups` - Returns `{ groups, total, limit, offset, hasMore }`
- `GET /listings` - Returns `{ listings, total, limit, offset, hasMore }`
- All endpoints backward compatible (return arrays if not paginated)
