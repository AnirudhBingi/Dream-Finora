# Issue Tracker

## Purpose

Track bugs, problems, and blockers encountered during development. Document solutions for future reference.

---

## Structure

```
docs/ISSUES/
├── README.md (this file)
├── ISSUE-001-[brief-description].md
├── ISSUE-002-[brief-description].md
└── RESOLVED.md (summary of resolved issues)
```

---

## Issue Categories

1. **Bug** - Something that's broken
2. **Blocker** - Prevents progress
3. **Performance** - Slow or inefficient
4. **Configuration** - Setup/environment issues
5. **Integration** - Third-party service issues
6. **Feature Request** - Future enhancements

---

## When to Create an Issue

- When you encounter a bug
- When something blocks your progress for >30 minutes
- When you find a workaround that should be documented
- When you discover a potential problem
- When a feature needs refinement
